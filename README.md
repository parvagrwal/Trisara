# Trisara

**Real-world assets came onchain without their clocks. Trisara is the escapement.**

[![CI](https://github.com/parvagrwal/Trisara/actions/workflows/ci.yml/badge.svg)](https://github.com/parvagrwal/Trisara/actions) [![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Trisara is session-aware infrastructure for tokenized stocks. Every guarded trade checks the market session before it executes — no more liquidations on stale weekend prices, no more swaps at Monday's open using Friday's close.

**Current state:** 128/128 tests green, live on 3 testnets (Robinhood Chain, HyperEVM, Tempo), 4 deterministic replays — guarded loses $0 where unguarded loses $782+. Testnet-only, self-reviewed, not audited.

Built for [Colosseum Crypto World's Fair](https://colosseum.com). Tracks: Tempo, Hyperliquid, Robinhood Chain.

## Pre-existing work disclosure

All code in this repository was written during the Crypto World's Fair hackathon window (Sept 14 – Oct 12, 2026). No pre-existing code, libraries, or contracts were reused. Third-party dependencies (forge-std) are listed in DEPENDENCY_INVENTORY.md.

## The problem

Chainlink equity feeds freeze when the market closes. Onchain routers keep trading against the frozen price because nothing onchain knows the market is closed. Measured over the weekend of Oct 9–12, 2026: up to 56.9 hours of staleness on a single feed.

The replay below is generated by `forge test`, not hand-written:

```
$ forge test --match-test ReplayHims

saturday:     CLOSED  →  DEFERRED, 0 fills outside collar, loss $0.00
monday open:  DISLOCATED → unguarded FILLED_AT_DISLOCATED, loss $782.56
```

## How it works

```
Guarded Router → GuardedFeed → PriceIntegrity → AnchorClock
```

- **AnchorClock** — onchain market calendar (NYSE hours + 2026-27 holiday bitmaps). Session state is a pure function of the block timestamp: no keeper, no oracle.
- **PriceIntegrity** — validates prices against session state (OPEN / CLOSED / REOPENING / STALE / DISLOCATED / HALTED / CHAIN_DEGRADED).
- **GuardedFeed** — session-aware price feed (collar/defer/halt when closed).
- **Rulebook** — standalone venue contract for custom session rules. Venues query it directly; it is not in the guarded routers' onchain call path.
- **Guarded routers/lender** — swap, borrow, and settlement with session enforcement. Exits always stay open: refunds, repayments, and withdrawals can never be blocked.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the full call paths.

```
graph TD
    A[GuardedSwapRouter] --> D[GuardedFeed]
    B[GuardedLender] --> D
    C[GuardedSettlementRouter] --> D
    D --> E[PriceIntegrity]
    E --> F[AnchorClock]
    F --> G[NYSE bitmaps 2026-27]
    F --> H[Fed holiday bitmaps]
    E --> I[ReferenceFeedAdapter]
    E --> J[PoolTwapAdapter]
    E --> K[HyperCoreAdapter]
    E --> L[TempoStableAdapter]
    E --> M[LivenessAdapter]
    N[Rulebook] -.-> O[Venues query directly]
    N -.-> P[Indexer + Signal API read offchain]
```

The guarded routers do **not** call the Rulebook on-chain. Session enforcement runs GuardedFeed → PriceIntegrity → AnchorClock. The Rulebook is a standalone venue contract.

## Columbus Day divergence proof (Oct 12, 2026)

On Monday Oct 12, 2026 (Columbus Day), the NYSE was open but the Federal Reserve was closed. AnchorClock's per-anchor calendars captured the divergence onchain:

| Anchor | Calendar | Oct 12 reading |
|--------|----------|----------------|
| NYSE (Robinhood 46630, HyperEVM 998) | Equities | OPEN |
| BANK_US (Tempo 42431) | Fed | CLOSED |

Verified onchain: Tempo AnchorClock `0x7F5C6E3eAACD95b3acDEC32Ab47d89887ceE74dA` returned CLOSED at 12:00 ET Oct 12 (holiday) and OPEN on Tue Oct 13 (banking day).

The stale weekend prints were off by up to 1.7% from the first live Monday prints (AAPL +1.72%, TSLA -0.63%, NVDA -1.15%). See [reports/weekend-2-oct10-11.md](reports/weekend-2-oct10-11.md).

## Known limitations

Published deliberately including the misses. Each is documented with measured evidence, not just the wins.

1. **BANK_US UTC day-boundary edge case** — on Fed holidays, 20:00–24:00 ET, the UTC date rolls before ET midnight, so `isOpen(BANK_US, ts)` reads true during those 4 hours. Permissive direction only (treats closed Fed as open), no funds at risk. Documented in [docs/BANK_US_EDGE_CASE.md](docs/BANK_US_EDGE_CASE.md); fix deferred to v2.
2. **Rulebook is not in the guarded routers' onchain call path** — session enforcement runs through GuardedFeed → PriceIntegrity → AnchorClock. The Rulebook is a standalone venue contract queried offchain by the indexer and signal API. Wiring `Rulebook.decision()` into consumers is future work.
3. **NVDA did not refresh at the Monday open** — in the Oct 12 observation window, NVDA stayed ~9,130s stale through 14:34 UTC while TSLA refreshed cleanly (4.8h → 4s). Feed behavior varies by symbol; the guard handles it, but the data is uneven.
4. **Lender liquidation design** — 100% collateral seizure on liquidation, LTV equals liquidation threshold (no buffer), keeper-set reference prices have no rate limits, and the reopen grace window does not trigger without a manual poke. Reviewed, not yet fixed.
5. **Zero-price handling** — when a feed returns zero, the guard serves a clamped collar price instead of halting. A fabricated price is worse than no price; this should halt.
6. **AnchorClock expires** — bitmaps cover 2026–2027 only. After 2027-12-31 the clock reads permanently CLOSED. Unscheduled closures (e.g. national mourning days) are not modeled.

## Secondary features

These exist but are not the main thing this project does. Treat their claims accordingly.

- **ProtectionBilling** — TIP-20 fee collection for the guard layer. Proposed monetization, not validated: no paying users, no signed LOIs, no fees collected on mainnet (testnet-only by decision).
- **Signal API** — offchain per-chain price signals for venues. Built to pilot scope for a design-partnership conversation; not production infrastructure.

## Roadmap

Each item follows from a finding above, not from a wishlist.

- **ET-midnight day indexing** — the BANK_US edge case points here: compute the day index from ET, not UTC. The contract already has DST logic, so this is derivable.
- **Rulebook-driven consumers** — wire `Rulebook.decision()` into consumer contracts so onchain enforcement matches the published policy. The Rulebook is also session-blind today; it should read the clock.
- **Halt on zero price** — replace the fabricated collar price with a halt when feeds return zero.
- **Lender economics** — separate max LTV from liquidation threshold, rate-limit keeper reference prices, fix the reopen grace window.
- **24/5 market phases** — model pre-market, post-market, and overnight sessions instead of binary OPEN/CLOSED.
- **CREATE2 deterministic deployment** — one address across all 3 chains, simplifies UI integration.
- **Unscheduled closures** — handle non-calendar halts and operation past 2027-12-31.
